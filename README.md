# Telefunken-CRT-TTV-5435-IR-CODES
Json file for the ir tv blaster app that contains Raw IR codes for the Telefunken CRT TTV-5435

1.Install the ir tv Blaster app
https://github.com/iodn/android-ir-blaster
2. Open the app and go to settings.
3. Search for Backup
4. Press import backup and select the file.
